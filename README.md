## 🚲 Bike Share SQL Analysis

A robust SQL-driven project modeling bike-sharing operational metrics and unit economics across multiple operating periods.

* **Schema Design & DDL**: Engineered a normalized relational database (`toman_bike_share`) with structured base tables (`bike_share_yr_0`, `bike_share_yr_1`)[cite: 1].
* **Cost & Pricing Integration**: Developed and populated a dedicated `cost_table` mapping annual pricing strategies against Cost of Goods Sold (COGS)[cite: 1].
* **Core Competencies**: Relational database architecture, data definition language (DDL), and structured data insertion for time-series analytics.
